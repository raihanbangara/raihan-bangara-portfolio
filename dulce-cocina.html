Brand identity

Homemade with love — a warm, hand-lettered mark for a bakery that had never had one.

The identity set the palette for the entire storefront: cream ground, cocoa type, and a soft rose accent carried through buttons, badges, and order confirmation emails.

The brief

A home bakery was taking orders through direct messages, losing track of them, and had no way to accept payment online.

I had no engineering background when I started. Rather than buy a template, I researched the stack myself so I would understand every part of it: an HTML, CSS, and JavaScript frontend on Vercel, a Node.js and Express API on Railway, PostgreSQL for order storage, Resend for transactional email, and UPI for payments.

Problems I solved
Problem 01 · Data loss
Orders disappeared on every redeploy

Order records lived in memory, so every Railway redeployment wiped them. I diagnosed the cause, then migrated storage to PostgreSQL so orders persist across deploys and restarts.

Problem 02 · Email delivery
Confirmation emails silently failed

Railway blocks outbound Gmail SMTP, which killed order confirmations with no obvious error. I re-architected the email flow around Resend's API and kept the whole thing inside free-tier sending limits.

Problem 03 · Payments
Checkout had to work end to end

I built UPI checkout from the frontend form through to backend order confirmation, so a customer can place and pay for an order without a single message being sent by hand.

Outcome

A fully deployed, functional production app, built alone.
